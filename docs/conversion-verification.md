# 中文、英文与数学验证报告

验证日期：2026-10-09。此报告已经更新为数学修正后的结果。完整逐例记录：[conversion-verification-results.json](conversion-verification-results.json)。

## 结果

- 中文：93 项规则检查通过，独立审计中的 11 项官方样例全部匹配。
- 英文：实际启用 liblouis 时，独立审计 8/8 匹配；强制启用原降级路径时仍有 7/8 不匹配。
- 数学：按 BANA Nemeth 2022 修正，新增 122 项规范点位、解析、边界和接入检查全部通过；独立审计扩展为 32 项，全部匹配。

数学是明确支持范围内的自动转写，不是对整部 Nemeth 规范的完整认证；也不能作为中国盲文数学标准实现。支持范围、复核标记和排版限制见 [数学转写说明](math-braille.md)。

CachyOS / Arch、Python 3.14。临时虚拟环境安装 pypinyin 0.55.0、jieba 0.42.1、pytest 9.1.1、PySide6 6.12.0、chardet 7.6.0。

系统原本没有 liblouis。为核对 native 英文，将 Arch 的 liblouis 3.39.0 解包到临时目录，通过 `LIBLOUIS_LIBRARY` 仅在验证进程中加载；未安装系统软件。英文表使用仓库内 `en-ueb-g2.ctb`，不是降级表。

| --- | ---: | ---: | ---: |
| 明确启用临时 liblouis | 338 | 0 | 0 |

数学测试合计 161 项：原功能与数学片段识别 39 项，新规范及回归 122 项。测试包含真正的完整点位比较，以及未知命令、结构错误和不支持的公式应产生复核标记的检查。两个原先断言错误上标点、错误数字下标的测试已改为官方例子的完整输出。

两次测试各有 2 条 pypinyin 的 Python 3.14 `codecs.open()` 弃用警告。Windows、打包和实体点显器没有在本环境中验证。

### 解析与接入检查

- `{a{b}c}` 正确处理嵌套 TeX 分组，不输出多余括号占位符。
- `\frac 123` 取单字符分子 1、分母 2，余下 3 回到原层级。
- `x^12` 只将 1 当作上标；`x^{12}` 将 12 整体作为上标。
- 同时上下标先下后上；分组后外加的上下标保留非同时的位置区别。
- 单个及多个撇号先于上下标，纯数字下标按规则省写。
- 括号内列表按 3.5/6.4.5 处理；出现比较符时不能套用列表省写。
- 行内/独立求和、显式 limits/nolimits、分数和根指数中的较小 TeX 样式分别检查。
- 总转换入口保留 Nemeth 开始/结束符；中文及英文正文标点紧接结束符。
- 未知命令、矩阵、连分数、缺失参数、错配括号、重复上下标等明确输出 ⠿ 并记录原因。

独立代码审查发现的星号后数字前缀、连续运算符、分组层级、撇号、列表和标点问题均加入了回归测试并修正。审查后的复现样例已再次核对。

## 复现

```bash
python -m pytest -q
python -m pytest tests/test_math_standard.py -q
python checks/verify_conversion_standards.py --output docs/conversion-verification-results.json
```

native 英文验证需实际启用 liblouis，可通过 `LIBLOUIS_LIBRARY` 指定库文件。库不可用时审计明确显示未验证 native 英文；强制降级项仍会导致审计返回 1。

## 证据范围

本报告只证明列出的输入与规则匹配。中文分词、多音字，数学字体/变体的语义区别、正文中是否切换数学体系、转写者说明及专业数学断行仍需人工判断。矩阵、空间方程组、多行对齐及连分数排版不在支持范围内；分页器尚未实现专业公式跨行、跨页保护。
