# 数学盲文转写说明

## 采用的规范

采用 BANA《The Nemeth Braille Code for Mathematics and Science Notation 2022》中的数学点位和结构规则。它是北美 Nemeth 体系；本模块不实现中国盲文数学标准。官方原文：[BANA Nemeth 2022](https://www.brailleauthority.org/sites/default/files/2024-02/Nemeth_2022.pdf)。

这是有明确支持范围的自动转写工具，输出仍需人工校订。点位检查不等于完成专业翻印所需的语义判读、转写者说明、公式换行和空间排版。

## 本次修正

| 项目 | 转写规则 | 官方位置 |
| --- | --- | --- |
| 数字与小数 | 使用下位数字；数字指示符按开始、空格、负号和星号等上下文决定 | 规则 3，例 3-6、3-11、3-36 |
| 运算与比较 | 普通运算符不加空格；比较符两侧留空；独立连续运算符与 `\pm` 区分 | 规则 20、21.13、24.1 |
| 上下标 | 上标 ⠘、下标 ⠰；记录完整层级，按需要回到基线；同时上下标先写下标 | 规则 14.4、14.8–14.11 |
| 数字下标省写 | 单个有独立身份的字母或函数名后的第一层纯数字下标省写指示符 | 规则 14.6、14.10.1 |
| 撇号 | 先写撇号，再写上下标；撇号前不加上标指示符 | 规则 14.12 |
| 分数 | ⠹ 分子 ⠌ 分母 ⠼；复合分数按阶数增加 dot 6；结束符恢复到起始层级 | 规则 13、14.9.1 |
| 根式 | ⠜ 被开方数 ⠻；根指数使用 ⠣；内部根式标明阶数 | 规则 16 |
| 希腊字母、字体 | 保留字母类别、大写和有意义的字体区别；不把希腊字母当成拉丁字母 | 规则 5–7 |
| 函数名 | `\sin`、`\cos`、`\log` 等名称后按规则留空 | 规则 18 |
| 括号列表 | 无比较符的列表中的字母、数字按规则省写指示符 | 规则 3.5、6.4.5 |
| 数学段与正文 | 加 Nemeth 开始 ⠸⠩、结束 ⠸⠱；正文标点紧跟结束符 | 规则 4、附录 B |

程序先解析公式结构，再生成盲文。TeX 不带花括号的参数只取一个字符：`x^12` 是上标 1、随后基线 2；`x^{12}` 才是上标 12。嵌套 `{...}` 是分组，不打印花括号；打印花括号需写 `\{...\}`。

## 支持范围

- ASCII 整数、小数，拉丁字母、标准希腊字母及 `\vartheta`、`\varphi`、`\varsigma`。
- `+ - = < >`、乘除、正负号、常见大小比较和包含关系，撇号、百分号等已列入点位表的符号。
- `\frac`、`\dfrac`、`\tfrac`，简单与复合分数；`\sqrt`、带指数根式、嵌套根式。
- `^`、`_`，同时或分组后的上下标、嵌套上下标、纯数字下标省写。
- `\sum`、`\prod`、`\int`、`\iint`、`\iiint`；常用函数名。
- 拉丁或希腊字母的粗体、斜体、花体、双线体等明确字体命令；`\ell` 保留花体区别。字体参数中包含一般数学运算或文本时不支持。
- 圆括号、方括号，显式花括号、尖括号与 `\lvert...\rvert`；匹配的 `\left...\right` 和常见尺寸命令。

行内公式默认使用侧边上下标，独立公式中的求和、连乘和极限默认使用正下方、正上方修饰结构。积分默认侧边上下标。`\limits` / `\nolimits` 可明确选择位置。分子、分母、上下标和根指数采用较小的 TeX 样式；开方内容沿用外层样式。

命令参数需要遵循 TeX 的单字符规则；小数参数请加花括号。普通输入中的逗号按列表分隔符处理，不自动猜测千位分组。希腊字母变体命令被视为作者有意区分的符号；如果整篇文章只使用变体而无语义区别，应按 6.2.2 由转写者统一并作说明。

## 不支持的结构与处理

矩阵、行列式、方程组的空间布局、`align` 对齐、多行公式、连分数、自定义宏、公式内 `\text{...}`、未列入表的箭头或修饰命令等不支持。空的必需参数、重复上下标、缺少定界符、未知命令和不支持的字符也需要人工复核。

上述输入返回单个 **⠿**，并记录含原公式及原因的警告。不会猜测宏含义，也不会删除关键结构后继续输出貌似完整的公式。程序识别到 `align` 数学区域时，其对齐内容仍属于不支持范围。

公式换行、跨页、数学片段整体保护和转写者说明尚未实现；当前分页器不保证专业数学断行规则。纯数字或单个变量是否在文章中采用 UEB，需按规则 4 结合上下文决定；目前显式 LaTeX 数学标记会进入 Nemeth。

## 调用与样例

```python
from src.converter.math_conv import latex_to_nemeth, nemeth_passage

latex_to_nemeth('x^2+1')
# ⠭⠘⠆⠐⠬⠂

latex_to_nemeth(r'\frac{1}{3}')
# ⠹⠂⠌⠒⠼

latex_to_nemeth(r'\sqrt[3]{2}')
# ⠣⠒⠜⠆⠻

nemeth_passage('1+2')
# ⠸⠩ ⠼⠂⠬⠆ ⠸⠱
```

`latex_to_nemeth(..., display=True)` 返回独立公式的数学内容，不带外层切换符。`nemeth_passage` 及应用总转换入口输出带切换符的数学段。`$...$`、`\(...\)` 是行内；`$$...$$`、`\[...\]`、支持的公式环境是独立公式。

验证证据见 [中文、英文与数学验证报告](conversion-verification.md)；逐格规范与解析回归检查见 `tests/test_math_standard.py`，独立审计见 `checks/verify_conversion_standards.py`。
