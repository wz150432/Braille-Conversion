# 中文盲文转写说明

## 规则来源

依据教育部、国家语言文字工作委员会、中国残疾人联合会发布的 **GF 0019—2018《国家通用盲文方案》**：

- [教育部发布页面](https://www.moe.gov.cn/jyb_sjzl/ziliao/A19/201807/t20180725_343690.html)
- [教育部规范原文 PDF](https://www.moe.gov.cn/jyb_sjzl/ziliao/A19/201807/W020180725666187054299.pdf)
- [教育部规范解读](https://www.moe.gov.cn/s78/A19/A19_ztzl/ztzl_yywzgfbz/guifanbzjs/201805/t20180521_336624.html)

这是按规范条文实现的自动转写程序，不是官方翻译软件或经过出版质量认证的翻印系统。规范条文优先于软件输出。

## 转写过程

连续中文段先形成候选连写单位，再逐词获取普通话本调，最后应用点位、标调、省写和简写规则。词间空一方，词内连写。

[pypinyin](https://github.com/mozillazg/python-pinyin) 只提供候选读音；[jieba](https://github.com/fxsjy/jieba) 只提供候选词界。两者都不是国家通用盲文规则实现，也不能保证语境判断符合专业编校要求。

## 模式

| 菜单模式 | API 值 | 声调 | 定字简写 |
| --- | --- | --- | --- |
| 省写与简写（默认） | `standard` | 按第 10.2 条省写及保调 | 按第 11 条使用 |
| 省写，不简写 | `tone_reduced` | 按第 10.2 条省写及保调 | 不使用 |
| 字字标调 | `full` | 按第 10.1 条保留本调 | 不使用 |

三种模式均保留第 9.4 条“他、它”的特殊拼写；轻声没有独立调号。“字字标调”不代表为轻声补一个调号。

旧接口 `toned=True` 对应 `full`；`toned=False` 对应 `standard`，含义已从“全部去调”改为“按规则省写”。同时传入 `mode` 时，以 `mode` 为准。

## 已实现的规则

| 内容 | 规范依据 | 实现 |
| --- | --- | --- |
| 声母、韵母、声调点位 | 第 5–7 条 | 单独的点位表；展开 `iu/ui/un`，处理 `y/w` 隔音字母及 `j/q/x` 后的 ü |
| 中文标点 | 第 8 条 | 中文句号、问号、书名号等采用中文表；双破折号、双省略号各对应一个盲文符号 |
| 音节拼写 | 第 9 条 | 舌尖韵母省略；“他、它”特殊拼写 |
| 标调 | 第 10.1 条 | 按本调，轻声不标调，不应用口语变调 |
| 声调省写 | 第 10.2.1–10.2.6 条 | 按声母和指定音节省写，保留 `tóu/lè/zì` 等例外 |
| 连写保调 | 第 10.2.7 条 | 声母自成音节后连写零声母音节时保调，如“慈爱、事业” |
| 语义和点位保调 | 第 10.2.8 条 | 包含“问、再、地道”等原例，其他语境可人工指定 |
| 定字简写 | 第 11 条 | 六个规定字按指定读音简写；“的、么、你、他、它”在同词内后接零声母音节时不简写 |
| 分词连写辅助 | 第 12 条 | 候选分词、规范原例、ABAB/AABB 重叠词和部分词缀/紧密结构处理 |
| 整数 | 附录 B | 连续数字共用数字号 `⠼` |

第 12 条包含语法、语义、惯用结构和语节判断。本项目只实现可确定的规则及部分候选校订，不能用普通分词器完整替代这些判断。四字及更长结构也不能一律切为二加二。

## 示例

下面给出默认模式下的规范原例，空格表示连写单位间空一方：

| 原文 | 盲文 | 说明 |
| --- | --- | --- |
| 你的 | `⠝⠙` | 两字简写 |
| 他用 | `⠞⠔⠹` | 同词内“用”零声母，“他”不简写 |
| 怎么样 | `⠵⠴⠄⠍⠢⠭` | “么”后连写零声母音节，不简写 |
| 慈爱 | `⠉⠂⠪` | “慈”保调 |
| 事业 | `⠱⠆⠑⠆` | “事”保调，“业”也是保调例外 |
| 再 / 在 | `⠵⠪⠆` / `⠵⠪` | 声调区分语义 |

## 人工校订接口

`ChineseWord` 可指定一个连写单位的逐字本调拼音，并指定需要保调的字序。字序从 0 起；读音使用数字调号，轻声用 5。

```python
from src.converter.chinese_conv import ChineseWord, chinese_to_braille

# 明确词界和多音字读音，不改动原文字序。
words = [
    ChineseWord('银行', readings=('yin2', 'hang2')),
    ChineseWord('行长', readings=('hang2', 'zhang3')),
]
braille = ''.join(chinese_to_braille('银行行长', words=words))

# 需要消歧时，校订人员可以显式保留某个字的声调。
braille = ''.join(chinese_to_braille(
    '在', words=[ChineseWord('在', readings=('zai4',), keep_tones=frozenset({0}))]
))
```

人工词界必须完整覆盖传入的连续中文段；不允许增删字符。未知读音按单字输出 `⠿` 并记录日志，不吞掉整段内容。桌面菜单提供模式选择，逐词校订目前通过上述程序接口进行。

## 支持范围与限制

- 本次完善针对普通话中文正文。姓名、专名、多音字、轻声、儿化及特殊语境应由校订人员核对读音和连写单位。
- 未实现正文小数、分数、百分数等中国盲文数学规则。正文扫描识别到小数时，小数点输出 `⠿` 并记录日志，避免误当中文句号。整数采用附录 B。
- 英文仍由现有 UEB 转换模块处理；缺少 liblouis 时降级为基本字母映射。数学公式仍走现有 Nemeth 模块，不能声称已符合中国盲文数学规范。
- 当前分页用于屏幕阅读，未完整实现专业出版的音节断行、段落、标题、表格等版式规定。正式翻印需要专业人员校订和排版。

中文模式贯穿纯中文、混合文本、公式旁的中文和逐页加载；切换模式会重新载入当前文档。
